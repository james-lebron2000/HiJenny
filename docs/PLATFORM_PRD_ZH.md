## 产品目标与验收口径

用户可以从一个药物、一个研究问题或一份客户材料开始，检索公开与私有证据，完成研究、交易、临床或医学事务工作，追踪执行结果，再检查之前的判断。个人用户购买研究能力；企业购买可在自身权限和数据环境中运行、由专家审核并可交接的工作流程。平台以临床尽调为首个商业场景，最终范围覆盖下列全部工作包。

本版扩展[既有交易工作台 PRD](PRD_v0.2_Noah_Inspired.md)。[单资产付费试点](PAID_PILOT_PRD_ZH.md)继续作为 Research 的首个交付规格。现有代码和文档显示已有本地证据提取、跨文档比较、问题复核、报告和导出。专业资料检索、全球数据库、企业访问控制、药物结局预测均需另行建设。表中“部分”表示有可复用组件，可交付程度仍以本版验收为准。现状依据：[工作台](../web/index.html)、[复核流程](../hijenny/diligence.py)、[评测说明](EVALUATION.md)、[安全现状](SECURITY_ONE_PAGER.md)。

**证据范围。** 本版依据公开页面与官方教程建立能力目录。官网定位属于厂商声明；教程和日历提供可观察的交互线索。登录后细节、专有数据权利、训练实现、模型性能及企业现场运行情况均待独立验证。“覆盖”指有对应需求和验收项目。达到同等性能需要同题、同数据边界的实测。以下功能形态和阈值是 HiJenny 的产品设计。

## 三条跨模块用户旅程

1. **BD 负责人准备评审会。** 在日历发现即将读出的资产，查竞品和可比交易，导入卖方材料；医学审核员解释 ORR 差异，BD 更新估值假设，导出内部简报与外发问题单。读出延期时只更新相关记录，保留上次会议的依据。
2. **医学事务负责人准备专家会。** 从专家发表记录进入证据检索，生成会前简报。会后将未解决的问题转成 IIT 或 RWE 概念书，数据成熟后生成可复算的表图、手稿和幻灯片，逐项保留引用与作者审核记录。
3. **临床开发团队比较研究方案。** 在同一证据截止日冻结两份候选设计，记录预测区间、适用人群与不确定性。专家批准后交由伙伴执行，系统接收实际结果与偏差，将结果交给独立验证人员，评估模型是否值得升级。

## 工作台、数据与状态

个人入口提供快速搜索、深度研究、数据库、日历、新闻和会议。企业入口按资产与项目组织，包含证据、Research、Clinical、Medical、审核队列、模型评估和管理后台。由数据库选中的记录进入 Agent 时传递选区、筛选条件与快照日期，返回结果时保留来源范围。

数据主链为来源版本 → 证据片段 → 具名实体与关系 → 分析结论或预测 → 决策 → 执行任务 → 观察结果。每个对象记录项目、权限、授权用途、业务发生日、首次可用日及版本。公共更正触发受影响清单；私有材料撤权后同步处理索引、缓存和导出入口。研究草稿经专业审核后发布，变更进入下一版。任务具备负责人、截止日、暂停、失败和重试状态。模型预测、专家意见、已观察事实在界面和导出件上分别标明。

## 质量评估与发布决定

| 能力 | 指标和评审办法 |
|---|---|
| 检索与图谱 | M0 建议按地区、语种、资产阶段分层冻结至少 100 个有答案及无答案问题。报告关键来源召回、实体误合并和引用语义正确率。对外发布的重大结论逐项签核；漏掉反向证据列为重大缺陷。 |
| 交付物 | 分别统计临床、医学、BD 任务的人工基准耗时、审核后采用率、重大错误与返工。重复测试锁定同一资料版本。首个 BD 项目沿用既有试点关键字段召回 ≥95%、引文正确率 ≥99% 的拟议目标，其他模块独立定标。 |
| 平台运行 | 建议首轮压测 20 人并发，普通筛选响应 P95 ≤3 秒；长任务显示进度，可取消或断点恢复。记录每次任务的来源调用、成本、额度、错误与恢复结果。企业测试覆盖原文、索引、模型网关、日志、备份与区域出站。 |
| 模型 | 首个验证任务建议限定肿瘤单一适应症与预定义终点。资产级去重，按时间切分并封存结局；连续读出评估绝对误差与区间覆盖，二分类推进结局评估 Brier 分数和校准。与阶段／适应症历史基线配对比较并报告置信区间。M0 预注册样本量依据、可接受误差、最低覆盖率、拒答规则和通过条件；无充分例数时延长观察。 |
| 商业 | 个人端按注册、首次带引文产物、付费、次月留存和单位任务毛利观测；企业端按正式订单、实付、客户签收、客户独立运行和续约观测。分别记录数据许可、推理及驻场成本。 |

**发布责任。** 产品负责人签功能，领域专家签内容，安全负责人签环境，独立验证人签模型。协议、知识库和工作台可在预测尚处研究阶段时独立发布。模拟和预测只在已验证的适用域逐步开放，保留数据不足、证据冲突和结果尚未成熟三种显式状态。
