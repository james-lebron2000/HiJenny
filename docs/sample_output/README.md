# 示例交付物 / Sample client deliverables

由 `hijenny demo-kit` 从仓库内合成示例资料包（ASD-101，13 份文档 / 284 页）生成：

| 文件 | 内容 |
|---|---|
| `HiJenny_Report.md` / `.docx` / `.pdf` | Due-diligence 报告：Decision Brief、证据矩阵、发现/缺口/问题、**Appendix A. Asset Discovery & Evaluation** |
| `Seller_Questions.xlsx` | 8-Sheet 工作簿：Executive Summary / Asset Profile / **Asset Evaluation** / **Discovery** / Evidence Matrix / Findings / Questions / Coverage |

重新生成：

```bash
hijenny demo-kit --out demo_workspace
# 或
./scripts/demo.sh
```

> 合成数据，仅用于产品演示；报告为人工复核草稿，不构成医疗/法律/投资建议，不自动给出 Go/No-Go。
