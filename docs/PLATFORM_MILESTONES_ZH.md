## 当前实现记录

HJ-03、HJ-07、HJ-11 已开始实现。从工作台进入的「医药检索」接入 PubMed 文献与 ClinicalTrials.gov 登记记录，可查看有来源的摘要片段及登记主要终点、批量收藏、按关键词筛选本机收藏和下载检索记录。桌面与移动导航均可返回尽调项目。在移动视口用 imatinib 实际查询两库，各取得十条记录，复验下载、刷新后保留收藏、筛选与移除。离线回归覆盖混合 XML 文本、零命中和空白查询。文献检索支持类型和发表年份组合过滤，指南支持发表年份；下载包含实际检索式、命中与取回数，限定条件可带入新底稿。跨地区授权数据、期刊指标和企业权限仍待验收。

HJ-08 已接入两来源研究底稿。用户可调整各库检索式，逐来源保存快照，复核记录并导出原始片段、链接及人工备注；复制计划产生独立版本。在移动浏览器实查 imatinib 获得 20 条来源记录；在可控的单库失败场景中验证刷新后只重试失败库、保存审核意见、导出与新旧版本切换。HJ-11 支持 2–4 项试验的十字段设计对照；用 NCT00115739 与 NCT02712112 验证移动端显示。上游接口出现过间歇连接失败。此阶段仍需专业人员判断证据冲突，已支持逐条筛选理由与可编辑 Word 证据报告，保留内容指纹、检索覆盖、纳入原文、排除记录和未完成来源；底稿可关联两条有分歧的来源，记录具名判断及理由，并在文本和 Word 中保留两端出处。正式用户验收仍待实施。

HJ-12 已接入本机试验关注列表、手动更新、预计与实际日期和字段变更历史。日历按时间列出两类完成日期，标出最近一次观察到的预计延期，可导出精确到日的全天事件；月份记录保留原精度。候选资产筛选页可按试验编号核对登记并直接加入关注；同一试验可回查多次入选的候选集快照。导出日历时可为日期精确到日的预计里程碑设置提前 1、7 或 30 天的本地上午 9 点提醒，由用户日历应用接收。公开资产动态支持按台北日期查看最近七天新发现的记录，可单独筛选字段变化、首次收录或原文核实，下载包含完整筛选结果与出处的文本简报。会议、新闻和登记变化的主动推送仍待实施。

HJ-15、HJ-16 已开始提供双方案设计工作区，可从临床试验比较带入登记字段快照，保存候选设计、取舍和待复核事项。修订版保留父版本，并列出变更影响。可记录本机填写的临床与统计复核人、时间、判断和理由，Word 方案摘要仅附当前版记录，修订版重新进入待复核状态。SAP 草稿可从指定设计带入人群、终点与对照，补充九项统计计划后导出；SAP 编辑产生新设计版本，保留变更并重新复核。Protocol 正文可按 A、B 分别起草实施、访视、安全监测等八章，导出选中设计、同版统计计划、变更与复核记录。CSR 可按候选设计录入汇总表文本，记录源表版本、逐行定位、截止日与录入文本指纹，导出受试者处置、疗效与安全性表。IB 可按产品与资料截止日期编制六章摘要，逐章带入来源、版本与定位，空章标记待补证。四类 Word 草稿均已接入；实际锁库、统计师复算、医学专业验收与正式签核仍待完成。

HJ-17 已实现从底稿纳入记录到专家会简报的本机工作流。首次使用者可直接填写会议问题和单独的公开检索词，运行两库检索，纳入来源后带回原问题与引文。新建会议可从医学工作台按原问题找回尚未生成简报的底稿，查看来源完成数和纳入数，并继续未完成的检索。医学人员可按题名、姓名或论文署名单位筛选已纳入论文中的作者，核对原文后将作者、PMID 与原文所列单位一起加入讨论对象；同名作者按论文内的署名位置区分，选择引文，保存外部问题、答复、讨论议程、行动负责人及期限；复核人具名确认后可导出对应版本。PowerPoint 中按署名记录列出讨论对象，单位过长时分页，每页可回到对应 PMID 核对。所选引文关联的底稿分歧会进入确认版文本和 PowerPoint，保留双方出处、判断和原复核人。团队身份认证、组织级医学审批与真实用户验收仍待完成。

HJ-18 已实现从确认版医学交流材料继承问题与来源、分别起草 IIT 和 RWE 方案、记录五项数据可行性依据、列出缺项、记录偏倚成因、可能影响、控制措施与剩余不确定性，保存修订版本并导出文本或可编辑 Word 提案。会议证据分歧及双方出处随提案继承，可逐项登记本研究的处理安排；缺失安排列入缺项，修改安排提示专业复核。偏倚修订触发原专业复核意见的重新确认提示。真实数据可用性和专业审阅仍需项目团队验证。

HJ-10 默认首页提供中英日任务入口，按商务拓展、临床开发、医学事务和证据研究直达对应工作台，并可进入同语种报价页。专业工作台仍以中文为主。中英日试点入口支持从首页直达、保留表单的语言切换、同一套规范化选项与受理编号；样例说明已翻译，完整下载报告为英文。三种语言均可展开 CSR 第 10 页与预测第 3 页的原页图、下载对应合成文件、核对两项 ORR 的原报值与复算值。三语企业入口已接入合成尽调报告、报价需求受理与编号；在部署环境使用 `python -m hijenny.cli pilot-inquiries --receipt 编号` 检索联络邮箱与范围，省略编号可列出队列。销售可用 `python -m hijenny.cli pilot-progress 编号 已报价 报价单编号` 登记进度；联系、报价、下单和回款分别留存时间与凭据引用。部署环境可运行 `python -m hijenny.cli pilot-metrics` 汇总累计数据：样例入口、展开、原页查看、报告下载请求及已受理询价按匿名标签页会话和样例版本去重；销售阶段按受理编号去重。可用 `--since YYYY-MM-DD` 按 UTC 首次打开或受理日期选择入组范围。会话可参加多个阶段，不能据此统计独立机构或推断因果转化。销售通过 `pilot-assign 受理编号 负责人 YYYY-MM-DD "下一步"` 指定本次跟进行动；`pilot-queue --waiting-quote` 列出新受理和最后登记为已联系的需求，可加 `--owner`、`--due-by` 筛选。无截止日的需求排在末尾，默认跳过已回款和已关闭。服务器 CLI 的 `pilot-quote` 可从受理记录生成可打印 HTML 报价草案；销售逐份填写固定总价、币种、税费口径、交付范围、交付时间及有效期，发送后用 `pilot-progress` 单独登记。服务器端可用 `pilot-delivery record 受理编号 版本 文件 发送凭据` 登记交付文件指纹，用 `pilot-delivery feedback 受理编号 版本 已验收或需返工 反馈 客户凭据` 登记客户结论，`pilot-delivery list 受理编号` 可回查各版。`pilot-delivery queue` 按最新交付版本列出待反馈和需返工的受理编号，显示客户反馈、凭据及当前负责人和待办期限；销售阶段不影响入列。经营汇总按受理日入组，区分交付版本数、最近交付的反馈状态、曾经验收的受理编号，以及其中已登记下单或回款的编号。实际报价、客户签收、订单及付款仍待业务验证。

试点样例提供独立的内部简报与卖方答复表。项目问题列表可导出已批准且未被驳回的问题、所需材料与空白卖方答复栏；内部完整尽调工作簿单独标识。卖方跟进页按项目显示各阶段问题数量，可筛选待答复、待复核、待验证和待更新简报等事项。已发布简报新增可比资产后，可重新复核并发布。

HJ-14 已提供项目内两情景买方风险调整净现值计算，支持逐项金额、概率、年份、假设来源、参照交易备注、关联卖方问题、历史版本和内部底稿导出。新估值继承候选资产名称与入选快照，可逐笔录入交易双方、授权范围、原币首付款、或有里程碑上限、披露日、来源及可比性限制；历史版本和内部导出保留当时口径。当前估值以本浏览器保存，实际交易数据授权和团队签核仍待完成。

HJ-13 已提供按药物或干预名称跨适应症查找登记试验，也可组合适应症、阶段、主要申办方和研究中心所在地筛选及分页快照。可按原条件和原取页数重新检索，逐项查看两个候选集新见、未见及登记字段的前后值；途中失败保留原快照。转为尽调项目时保留所选资产、登记来源、筛选条件与入选依据；尽调项目保留筛选地区和实际登记的中心国家清单。候选页和项目来源按每项干预展示登记别名；两版均采集别名时可核对映射变化。可按结果是否已在登记库公布筛选，查看首次公布日期、登记结果原文、终点和安全性表；结果状态变化可随复查对照。可比交易、权属和竞争覆盖仍需独立核实。

HJ-11 进一步支持按 NCT 编号查阅已发布的结果。可按终点检查组别、分母、单位、报告区间、分析人群及安全性表，下载快照，或将选中的终点带入待复核研究底稿。数据保留登记口径，原始统计分析另见来源。医药检索同时支持按 PubMed 指南与实践指南文献类型检索，显示收录类型及发表日期；指南适用地区、推荐分级和发布方更新情况需要核对原文。

HJ-06 的 PubMed 检索快照已保留撤稿、更正、编辑关注及相关重刊标记，可查关联 PMID，并随收藏、底稿、专家会及研究提案导出。已有底稿可按 PMID 手动复查出版标记并保存独立新版；标记变化或记录无法核实时重新进入待复核，原版可回查。专家会工作台按已确认简报的实际引文与本机后续复查快照比对，列出标记不同或最近未能核实的 PMID，并可回到对应底稿。可从受影响简报发起修订，沿用原问题与答复，从复查版底稿重新选引文，记录影响及理由后另行确认。后台自动通知待实现。

## 执行清单

编号与 PRD 一一对应。每个项目由下列牵头角色维护，完成时附演示记录、可复验样本、评审人和日期。跨组并行开发可用合成或已授权样本，发布依赖以总计划为准。

### M0　立项与评测冻结

- [ ] **HJ-01 范围与验收合同**（产品）。按四类用户访谈，冻结目标工作流、对标地区、可测任务和采购场景。验收凭据应证明：BD、临床、医学、个人研究者各确认一个真实任务，历史路线与新增范围可区分。
- [ ] **HJ-02 数据授权与评测集**（数据治理）。登记来源许可、客户归属、数据截止日，分别封存检索、生成和预测留出集。验收凭据应证明：每份测试材料能查到用途、授权或替代数据；登记建设与验收责任人。

### M1　公共数据与企业隔离底座

- [ ] **HJ-03 四地区数据接入**（数据工程）。接入中、美、日、欧的试验、文献、专利、监管记录，并纳入许可范围内会议、公告、指南和交易来源。验收凭据应证明：四地区×四类核心来源覆盖矩阵列出样本、许可、最近成功时间、延迟和缺口；抽查每个格子的原始记录。
- [ ] **HJ-04 医药本体与专家校订**（知识工程）。统一药物、靶点、适应症、人群、公司、试验、测定、终点和监管事件；处理跨语别名、出处与版本。验收凭据应证明：同物异名能合并，同名异物能拆分；审核员可否决关系、回滚合并并回查历史图谱。
- [ ] **HJ-05 企业私有知识与证据权限**（平台安全）。内部原件及衍生实体关联公共证据，搜索、缓存、引用、导出继承项目权限。验收凭据应证明：两个租户使用同名资产测试；撤权后搜索、导出、原文和缓存均拒绝越权访问。
- [ ] **HJ-06 来源与专家裁决**（质量负责人）。保留来源版本、位置、原文、语义支持状态、冲突、审核人及签核版本。验收凭据应证明：对冲突、撤回和不可访问来源各跑一例，所有受影响的摘要提示复核，旧版可追溯。

### M2　个人工作台与商业入口

- [ ] **HJ-07 快速检索与研究助手**（搜索产品）。提供 PubMed 和权威健康来源检索、指南筛选、追问、带出处的答案与个人收藏；按文型、主题与获授权期刊指标过滤。验收凭据应证明：用户由问题定位到支持段落；无来源时显示缺口；个人知识库可批量保存及重新检索。
- [ ] **HJ-08 多步深度研究**（Agent 工程）。澄清范围、生成可改计划、查询多源数据库、整理证据表、自检覆盖并导出报告。验收凭据应证明：中断后可继续；展示使用来源、失败步骤、冲突和用量；重复执行保留独立版本。
- [ ] **HJ-09 注册、套餐与用量**（商业产品）。自助注册和登录、免费额度、分级月年订阅、团队咨询；数据库查询、API 调用与研究任务分别计量。验收凭据应证明：沙箱支付验证开通、升级折抵、续费、取消、耗尽与失败退还；同一支付回调只记一次。
- [ ] **HJ-10 多语入口与公开内容**（增长产品）。中英日导航、样例、文章、研究洞察与新手教程，企业咨询转交驻场团队。验收凭据应证明：三种语言可从首页进入同一示例或提交需求；内容标注审校人和更新日。

### M3　Research 与首个 BD 客户

- [ ] **HJ-11 临床结果、管线与指南数据库**（数据产品）。按资产、公司、阶段、地区、人群、终点过滤，选中记录直接比较或问答；指南附适用地域和版本。验收凭据应证明：指定资产能查管线、结果、指南三类记录；跨试验不匹配维度逐项显示。
  - 支持从收藏夹或同次检索中选取 2–4 项试验，各自选择已公布的终点，对照人群、定义、时间窗、分母和登记值，下载含检索时间、来源与所选终点的 JSON。跨试验可比性由审阅人判断。
- [ ] **HJ-12 事件日历、新闻和会议中心**（情报产品）。跟踪会议摘要、读出、申报、批准与交易，提供事件详情、上下文问答、关注列表和提醒。验收凭据应证明：预期、延期、已发生分别呈现；同源转载去重，日期修改只发一次更新；事件能回到资产。
- [ ] **HJ-13 机会识别与竞争情报**（BD 产品）。按买方策略选候选资产、候选伙伴和竞争项目，展示入选依据、遗漏范围与关键催化剂。验收凭据应证明：BD 在限定适应症下保存筛选式、复现候选集并把其中一项转为尽调项目。
- [ ] **HJ-14 估值、交易与卖方复核**（交易分析）。以可比交易、情景现金流、成功概率和条款假设形成估值范围；连接已有卖方问题、答复及决策简报。验收凭据应证明：每个数字附来源或假设、币种和时间；变更一项参数可复算；内外部导出分离，专家签核可追溯。

### M4　Clinical 工作台

- [ ] **HJ-15 研究设计与入排标准**（临床开发）。临床团队输入研究问题和证据约束，比较人群、对照、终点、可行性，起草方案及入排条款。验收凭据应证明：临床负责人核对至少两种设计的取舍；修改一项人群定义后列出受影响章节。
- [ ] **HJ-16 Protocol、CSR、IB、SAP 编写**（医学写作）。将批准的方案、锁定统计表和参考资料映射到模板，生成可编辑草稿、字段来源与版本差异。验收凭据应证明：四类文件各交一份；统计师复算抽查的数值；未提供的结果保留空缺；变更触发重新签核。

### M5　Medical 工作台

- [ ] **HJ-17 KOL 交流与医学问答**（医学事务）。按公开专业方向检索专家，起草会前简报、证据答复和会后行动记录，绑定医学审核人。验收凭据应证明：医学人员从一项外部问题回到证据和获批答复版本；会议材料经人工确认后可导出。
- [ ] **HJ-18 IIT 与 RWE 研究设计**（真实世界研究）。输入未满足的证据需求及可用数据，产出研究者发起研究概念书、真实世界研究方案、偏倚和数据可行性评估。验收凭据应证明：流行病学与统计审核人检查人群、暴露、结局、随访、混杂和缺失处理；保留修改记录。
- [ ] **HJ-19 医学写作、分析、图表与幻灯片**（发表负责人）。选题和综述形成证据矩阵；从授权数据生成分析表、数据图、示意图、摘要、手稿、翻译和汇报稿。验收凭据应证明：同行可复算表图，译稿数字一致；示意图标识性质，幻灯片与手稿引用同一版本，作者审核后导出。
  - 专家会已确认版本支持导出可编辑 PowerPoint，逐条引用保留原文与来源链接，附行动、负责人和期限。发表写作、授权数据复算和跨稿件引用一致性仍待验收。

### M6　企业驻场与项目执行

- [ ] **HJ-20 私有部署、驻留与可信交付**（安全负责人）。客户环境部署、SSO、项目角色、加密、密钥、可关模型网关、审计、备份与删除；中国和全球区域分别核验。验收凭据应证明：完成区域数据流与恢复演练；认证项目另行出具独立机构证书、主体、范围和有效期。
- [ ] **HJ-21 驻场服务及客户接管**（驻场交付）。药企专家与工程师共同梳理用例；首周用客户获准数据交一份工作成果；移交环境、工作流、约定的模型制品及运行手册。验收凭据应证明：客户管理员独立部署、升级、恢复和导出；合同列清底模、定制权重、客户数据权利及第三方许可。
- [ ] **HJ-22 实验与临床任务协同**（集成工程）。把专家批准的计划转换为任务和责任人，接入实验室或临床项目管理系统；回收状态、结果、偏差和未完成原因。验收凭据应证明：在伙伴测试环境独立演练实验与临床两类任务；重复回执不重复建档，失败结果仍入项目历史。

### M7　世界模型回顾性研究

- [ ] **HJ-23 药物全生命周期轨迹**（模型数据）。链接前临床证据、临床设计、各阶段读出、终止及监管结局，按当时可见信息重建时间截面。验收凭据应证明：逐条审计事件可用日期、结局定义、未成熟结局和授权；同资产及相关试验分组隔离。
- [ ] **HJ-24 世界模型与方案模拟**（模型科学）。在明确的适用域内估计不同机制、人群和设计下的读出分布与项目推进概率，显示区间和适用边界。验收凭据应证明：用冻结的时间外样本与领域基线比较校准、预测误差和区间覆盖；披露失败及数据稀疏亚组。

### M8　前瞻验证与全平台验收

- [ ] **HJ-25 结果学习与前瞻验证**（独立验证）。在观察结果前锁定模型、输入、预测和区间；真实读出回填，授权数据进入候选版本训练，保留可回滚版本。验收凭据应证明：独立人员核对预测时间戳、遗漏项目和失败结果；同一盲集比较版本，按预注册门槛决定发布。
- [ ] **HJ-26 模拟至学习的全程验收**（项目验收）。负责人比较方案，批准一项执行任务，在结局成熟后回看预测与实际差异，审议新版本的适用范围。验收凭据应证明：客户用一个授权案例从模拟走到结果回填；审核轨迹、模型归属、发布依据及整套交接资料均可导出。

## 资源、依赖与调度

建议立项配置为产品与设计 2 人，应用与平台工程 4 人，数据与知识工程 3 人，模型与评测 3 人，质量与安全 2 人，驻场交付 1 人；另由客户与团队明确临床、统计、医学和交易的具名审核人。以上为排期假设。人力减半时先保 M1、M2、M3 和模型数据审计，将 M4、M5 串行。预算分设数据许可、基础设施及推理、专家审核、驻场、模型验证五项，M0 用供应商报价与样本工作量估算，分别批准业务和研究预算。

关键路径为 M0 → M1 → M2 → 三个专业产品 → M6 客户接管。预测路径从 M0 冻结任务后提前收集授权轨迹，经 M7 时间外验证、M8 前瞻读出和独立审议后发布。源许可未就绪时登记地区与类型缺口；结局不成熟时保留研究状态；客户环境未获批准时使用公开或合成样本完成开发。

**首两周可直接分派。** 第 1–2 天由发起人指定每个工作包的具名负责人；第 3–5 天由领域负责人提交四个用户任务、输入样本与合格输出；第 6–8 天由数据和安全负责人提交许可矩阵、流向及成本；第 9–10 天由各方冻结首个场景、评测设计、M1 预算和验收人。每两周评审已验收工作包、阻塞依赖、采购和质量证据。范围变化同时更新 PRD 编号与本清单。
